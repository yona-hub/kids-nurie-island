# 塗り心地と見た目の品質を改善する計画

## 方針

「少ないタップで進み、選んだ画材らしく、美しく仕上がる」体験へ改修する。対象は正式線画10枚、ホーム12島、背景11種・フレーム21種。

決定した仕様は次のとおり。

- 標準はまとめ塗り。細かく塗り分ける部分モードも残す。
- 目は常に自動補正。手動でハイライトを塗る操作は廃止する。
- 陰影は上品な絵本調。クレヨン・いろえんぴつの特徴は原寸でもはっきり見せる。
- 保存済み作品は保持し、色を引き継いだ改善版を別作品として作れるようにする。

## 塗り方・目・画材

**まとめ塗り**

- 線画ごとに「同じ人物の肌」「髪全体」「同じ服の各部分」などの意味に基づくグループを制作する。材質や現在の色だけによる自動判定は使わない。
- 肌は顔・両耳・首・手・露出した足をまとめる。口、瞳、服、手袋、別の人物・動物は分ける。
- おひめさまは髪全体、肌全体、上半身の服、スカート、リボンをそれぞれグループ化。魔法使いは帽子とつば、髪、肌、マントと袖、ズボン、靴などをまとめる。
- 残る8枚も、動物ごとの体、車体パネル、タイヤ、花ごとの花びらなど、対象物と意図した塗り分けに合わせて設定する。
- グループ内のどこをタップしても全構成領域を同じ色・画材へ更新する。消しゴムも選択中のモードに従う。
- 一度のタップを一度の描画更新・保存として扱う。部分モードでは小領域を個別に塗れる。

**目の自動補正**

- 選んだ色を虹彩の基調色に使い、中央の暗い瞳、上側の柔らかな陰影、白い主反射光と小さな補助光を生成する。
- 現在のハイライトを囲む黒い輪を改善版から除き、輪郭のない自然な反射光にする。光の向きは左右で統一する。
- ハイライト部分へのタップも瞳への操作として扱う。まとめ塗りでは同じキャラクターの両目、部分モードでは片目ずつ塗れる。
- 未着色時は白黒線画を保ち、目を消した場合は補正も消える。

**画材と陰影**

- なめらか：均一な塗膜と柔らかな立体感。
- クレヨン：蝋の厚い顔料、紙の凹凸による細かな抜け、不規則な粒、幅のある短い筆跡。
- いろえんぴつ：細い方向性のある筆跡、筆圧差、半透明の重ね塗り、紙の繊維が透ける表現。
- 現在の白い線を重ねる方式から、紙目・顔料の乗り方・筆圧を組み合わせる方式へ変更する。紙目と画材用マスク3種は画像生成し、制作時に調整して使用する。
- 質感の座標とseedを固定し、拡大、再読込、PNG出力で模様が変わらないようにする。肌にも選択した画材の特徴を残す。
- 髪の艶は毛流れに沿わせ、服は折り目に沿わせる。小領域ごとに陰影がリセットされる現状を改め、グループ共通の光源と制作した陰影情報を使う。

## 原寸・拡大時の描画品質

- 生成原画を使い、輪郭を滑らかなベジェ曲線へ再構築する。キャラクター、構図、部位の対応を維持し、角・穴・細い領域を保護する。
- 塗りマスクと線を整合させ、境界の白い隙間、色漏れ、二重の輪郭を除く。紙目として意図した微細な抜けと、不具合による塗り残しを区別する。
- 改善版は、表示範囲を端末の画素密度と拡大率に合わせて描く方式へ変更する。低解像度CanvasをCSSで引き伸ばす処理を置き換える。
- 拡大範囲は現在と同じ1〜4倍。表示範囲だけをタイル描画し、境界に重なりを持たせて継ぎ目を防ぐ。タイルと画像のキャッシュはそれぞれ32MiBの上限を持つ。
- 編集、完成画面、サムネイル、2048×2560 PNGで同じ描画規則を使う。

## ホーム・背景・フレーム

**ホーム**

- キャッチコピーと案内文を撤去し、コンパクトなロゴ・設定の直下から島を表示する。
- 文字用の島を撤去。テーマ名をイラスト内に組み込み、王冠・花・星などと合わせた装飾文字にする。
- 文字はSVGの曲線配置で鮮明に描き、軽い弧と傾きを付ける。日本語の正確さ、読みやすさ、ボタンの読み上げ名を維持する。
- 既存の生成済み島イラストを生かし、余白とカード比率を調整する。390×844では初期表示に8島以上、320px幅でも横にはみ出さない配置を目標とする。
- 作品・続きからの導線は一覧下のコンパクトな操作として整理する。

**装飾素材**

- 星、雲、虹、雫、王冠、宝石、花、葉、貝、足跡、化石、タイヤ、コーン、歯車、惑星、果物、玩具、画材など、現行フレームの26種類のモチーフを透明背景で個別に画像生成する。
- 背景用に浮島、草地、遠景の木、花の群落、海面、海藻、サンゴ、城の塔、岩場、未来都市の遠景を個別に生成する。
- 素材を組み合わせ、テーマごとに配置・大きさ・間隔を変える。背景中央は主役が見える低コントラストにし、フレームは顔・髪・手に重ならない構成にする。
- 実行時も個別素材を適切な解像度で合成する。合成manifestと素材はhash付きURLで配信し、選んだ背景・枠に必要なものだけ取得する。
- 白背景・枠なしを含む、選択可能な11背景・21フレームを維持する。

## 互換性・制作順序・合格条件

**データと互換性**

- `Template`へ塗りグループ、目の対応、陰影情報、旧領域との対応表を追加する。描画エンジンに複数領域の一括更新とviewport描画のインターフェースを追加する。
- `RegionPaint`の色・画材と作品保存schemaは維持する。新しい描画規則と塗りモードは既存の作品metadataで識別し、DB migrationは追加しない。
- 輪郭を変更する改善版には新しいtemplate IDを付ける。旧線画・旧描画・旧装飾素材を保持し、保存済み作品の元の状態を残す。
- 「改善版をつくる」で別作品へ色をコピーする。元作品を上書きせず、500作品上限や保存失敗時にも保持する。
- 旧採用記録を新しいhashへ流用しない。今回の自動ハイライト指定を最新仕様として記録する。

**制作順序**

1. おひめさまと魔法使いで、まとめ塗り・自動補正・3画材・輪郭を完成させる。
2. 同じ色・同じ部位の3画材比較、原寸、2倍、4倍、PNGの確認画像を作り、見た目の基準を確立する。
3. 残る8線画とホーム・装飾素材へ展開し、変更後の候補を制作レビューへ提示する。
4. 最新版の検証と関連担当の独立再監査を行い、最終判定を更新する。

**合格条件**

- 髪の一箇所で髪全体、魔法使いの顔で両耳・首・両手が塗れる。別キャラクターや口・服へ塗りが及ばない。
- 原寸でも3画材を視覚的に区別でき、顔・帽子・胴体にも選んだ画材の特徴が出る。
- 目に黒いハイライトの輪が残らず、黒・青・淡色でも自然な反射光になる。
- 全10枚を1・2・4倍、DPR1・2・3で確認し、輪郭の粗さ、タイルの継ぎ目、意図しない塗り残し・漏れがない。
- 旧作品の保持、改善版へのコピー、部分塗り、保存・再読込・同期・PNGを検証する。
- 新ホームと装飾の実画面を確認後、Visual基準を更新する。自動検査と原寸・拡大の目視確認を合わせて合否を決める。
- 固定buildで最大グループの描画性能を測り、CPU4倍／DPR2の初回Canvas描画p95 100ms以内を確認する。実機性能は別途確認する。

外部公開、共通ハーネスCoreの変更、有料APIへの切替は含めない。前回のPASSは旧版の記録として保持し、改善版の品質判定には新しい証拠を使う。

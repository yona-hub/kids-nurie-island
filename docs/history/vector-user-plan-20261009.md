## 描画方式

**ベクターを使う方針です。** 現状もベクターの輪郭を使っていますが、元画像の細かな凹凸を大量の曲線で残しています。これを滑らかなベジェ曲線へ再構築します。線・塗り面・目の輪郭はベクター、画材の質感は生成素材と固定seed描画を組み合わせます。[SVGの曲線・塗りの仕様](https://www.w3.org/TR/SVG2/paths.html)

デメリットは、輪郭を整える制作工数と、複雑な曲線による描画負荷です。また、ベクター化だけでは紙目や蝋の質感は改善しません。現在のCanvasとタイル描画を生かし、拡大率と端末の画素密度に合わせて再描画します。目標は、1〜4倍で解像度不足による粗さが増えないことです。[Canvasと画素密度](https://developer.mozilla.org/en-US/docs/Web/API/Window/devicePixelRatio)

## 輪郭と白い塗り残し

- 全10枚の曲線を再構築する。キャラクター・構図・角・穴・細い部位を保ち、短い曲線を大量に並べる現在の変換を置き換える。
- 線・塗り境界・当たり判定を同じ制作データから生成する。塗りは黒線の下まで覆い、背景や隣の領域へ漏らさない。
- 白い下地を領域ごとに重ねる処理を見直し、後から描く領域が隣の色を白く削らない構成にする。
- タイル合成と端末の画素密度変更を確認する。低解像度画像の引き伸ばしを避け、編集・完成画面・サムネイル・PNGで同じ描画規則を使う。
- 塗り残しの原因は未確定。まず「なめらか」で境界の欠けを検査し、その後、クレヨン・鉛筆の意図した紙目と区別する。

## 目と乗り物

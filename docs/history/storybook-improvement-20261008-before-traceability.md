# 絵本調・塗り心地の改善（2026-10-08）

ユーザーが実装を指示した計画に基づく新しい版。旧版の品質判定・原画・承認・作品は保持する。

- まとめ塗りを標準とし、部分モードを残す。人物の髪・露出した肌、物のまとまりは線画ごとの明示データで定義する。
- 瞳は選択色の虹彩・暗い中央・白い反射光を自動描画する。以前の「ハイライトを手動で塗る」指示は今回の「常に自動補正」に更新された。
- 同日の追加指定で、未着色時には瞳とハイライトの枠を表示する。着色後は選択色の周囲グラデーション、大きな暗い瞳、輪郭なしの反射光へ変える。人間・動物・きょうりゅうにも共通適用する。
- 最新のユーザー指摘でrevision 3の比較画像は却下された。ホーム原画の白目、上まぶたの影、虹彩繊維と明るい下側、小さな右上反射光、目の傾きと比率を具体的な比較基準にする。技術的に反射光があるだけでは見た目の合格にしない。
- 3画材を原寸でも区別できる紙目・顔料・筆跡にする。陰影は絵本調。拡大は1〜4倍で表示範囲を直接描く。
- ホームのキャッチコピーと文字用の島を廃し、島内の装飾文字とコンパクトな配置へ変更する。
- 26モチーフ・10背景パーツ・3画材マスクをbuilt-in image_genで個別制作する。元画像・プロンプト・公開hashを記録する。
- 旧作品は保持。新template IDと明示領域対応で改善版を別作品へコピーする。DB schemaは変更しない。

## 受入条件

髪全体/人物の肌全体を1操作で塗れる。他人物・口・服への漏れなし。部分モード・消去も保存後に保持。黒/青/淡色の瞳で黒い反射光の輪を残さない。全10枚の1/2/4倍、DPR1/2/3で線・塗り・継ぎ目を確認する。3画材の同色比較を原寸とPNGで目視する。旧版と改善版の元作品保持・コピー・上限・保存失敗・再読込を確認する。

390×844で8島以上の初期表示、320px幅の横はみ出しなし。装飾は画像生成パーツを合成し主役を保護する。最新固定buildで最大グループのCPU4/DPR2描画p95 100ms以内を検証する。旧PASSは新しい版へ転記しない。

## 現在の状態

実装中。新しい線画は技術レビュー候補として扱い、旧人間承認を新hashへ流用しない。外部公開・実機検証・有料API・共通Core変更は含めない。

# キッズ塗り絵アイランド — 高品質プロトタイプ＋全機能実装

あなたは本プロジェクトのメイン実装エージェント兼テックリードです。

「キッズ塗り絵アイランド」のWeb/PWA版について、
以下に定義する仕様を満たす高品質な実動プロトタイプを完成させてください。

単なるデモ・モックではなく、
今後公式線画420枚規模へそのまま拡張できる本実装品質を目標とします。

プロトタイプ段階では10枚の正式な塗り絵線画を実装し、
描画・認証・クラウド保存・PWA・作品管理・背景・フレーム・設定・レスポンシブUI・制作パイプラインまで、
仕様に記載した機能を実際に動作させてください。

品質・性能・保守性・UXを最優先してください。
安易な簡略化、仮実装、見た目だけのモック、TODO放置は禁止です。

外部サービスの実Credentialsなど、どうしてもユーザー側設定が必要な項目のみ例外とし、
その場合もコード、SQL、設定テンプレート、手順書までは完全に実装してください。


==================================================
1. プロダクト概要
==================================================

アプリ名：
キッズ塗り絵アイランド

形式：
無料Webアプリ + PWA

初回リリースでは以下を行わない：
- 投稿
- 他ユーザー作品閲覧
- いいね
- コメント
- フォロー
- SNS機能
- 広告
- 課金
- 公開プロフィール

アカウント連携：
必須。

初期リリースではGoogle認証のみ表示する。
ただしAuth実装はprovider依存にせず、
将来Microsoft、LINE等を追加できる抽象化を行う。

ログイン画面に
「保護者の方がログインしてください」
等の注意文言は表示しない。

例：
「作品を保存するため、ログインしてください」
[ Googleでログイン ]

Googleのメールアドレス等を独自profilesテーブルへ不要に複製しない。
アプリ内部ではSupabase Authのuser_idを基準に扱う。

==================================================
3. 保存・クラウド同期
==================================================

Supabaseをユーザー作品データの正本とする。

IndexedDBは以下の用途：
- 即時自動保存
- オフライン編集
- 高速表示
- 同期待ちデータ
- 最近使った公式素材のキャッシュ

作品操作時：

ユーザー操作
↓
IndexedDBへ即時保存
↓
UIを待たせない
↓
最後の変更から1～2秒程度debounce
↓
Supabaseへ同期

以下では同期を即時試行：
- 完成
- ホームへ戻る
- ページ非表示
- 背景変更
- フレーム変更

Supabaseへ保存するもの：
- project id
- user_id
- template_id
- status
- regionごとの色
- regionごとの画材
- background_id
- frame_id
- created_at
- updated_at
- version
- thumbnail
- 必要なproject metadata

保存しない一時UI状態：
- Undo用内部履歴
- zoom倍率
- pan位置
- パレット表示状態
- 開いている色グループ
- 塗り演出中状態

PNG完成画像そのものを正本として保存しない。

作品は状態データから再描画可能にする。

作品サムネイルのみ小容量WebP等として保存可。


==================================================
4. 同期競合
==================================================

同じ作品を複数端末から編集した場合、
古い端末からの更新で新しい作品を黙って上書きしてはいけない。

versionで競合判定する。

競合時：
- 新しいクラウド版を保護
- 古い端末側の変更も失わない
- 古い端末側を「別作品」として複製保存する

UI上では
「競合」「マージ」
などの技術用語を使わない。

分かりやすい表現にする。


==================================================
5. 同期状態表示
==================================================

正常時：
原則表示しない。

同期中：
「保存しています…」

オフラインだがIndexedDB保存済み：
「この端末に保存済みです」
「ネット接続後に自動で同期します」

通信可能だが同期失敗：
「この端末に保存済みです」
「同期できていません」
[再試行]

長時間未同期の場合は設定画面にも表示：
「未同期の作品が○件あります」
[今すぐ同期]

ユーザーに
「保存されているのか分からない」
という不安を与えないこと。

==================================================
10. 線画フォーマット
==================================================

基本アスペクト比：
4:5 縦

論理キャンバス：
1600 × 2000

SVG：
viewBox="0 0 1600 2000"

PNG標準出力：
2048 × 2560

作品ごとにアスペクト比を変更しない。

横長の乗り物等も構図側で4:5に最適化する。

AI/生成線画制作規格：
- 純白背景
- 黒線
- 基準線幅10～14px相当
- 全塗り領域を閉じる
- 陰影なし
- グレーなし
- グラデーションなし
- ハッチングなし
- 線の意図的な切れ禁止
- 極小領域回避
- 塗れる領域の最小幅目安24px
- 線同士の曖昧な接触禁止
- 主役を安全領域内へ収める

==================================================
12. 線画制作・領域分割パイプライン
==================================================

実行時に領域解析しない。

制作時にアセットへコンパイルする。

tools/asset-pipelineとして、
本体とは独立した制作ツールを作る。

推奨：
Python + OpenCV

工程：

元線画
↓
グレースケール
↓
二値化
↓
解析用mask生成
↓
Morphological Close
↓
必要最小限のdilate
↓
Connected Components
↓
領域検出
↓
自動QA
↓
findContours
↓
SVG Path / region map
↓
素材判定
↓
陰影map
↓
質感map
↓
アプリ用asset package

見た目の原画そのものを、
領域解析補正で破壊しない。

originalとanalysis-maskを分離する。

軽微な1～3px程度の線切れのみ自動修復候補。

大きな線切れを勝手に補完せず、
NG判定する。

QA項目例：
- 領域数
- 背景漏れ
- 微小領域
- 異常巨大領域
- 閉領域失敗
- 線画白黒率
- 最小幅
- contour異常
- SVG生成失敗

debug-previewとして
領域を異なる色で塗った画像を生成する。

==================================================
14. スマート質感
==================================================

初期素材タイプ：

- 標準
- 肌
- 髪
- 毛
- 布
- 金属
- プラスチック
- ガラス
- ゴム
- 木
- 石

表示名は制作UIでは日本語。

内部IDは英語でよい。

見た目：

標準：
左上に弱い明部、右下に弱い陰影。
クセのない基本。

肌：
非常に滑らか。
広く薄い影。
弱いハイライト。
粒子なし。

髪：
毛流れに沿った2～4本程度の柔らかな明暗帯。
帯状の光沢。

毛：
短い不規則な毛並み。
低コントラスト。

布：
ふくらみ・折り目に沿う広い陰影。
光沢ほぼなし。

金属：
エッジに細い明部。
一部に強めのハイライト。
陰影とのコントラスト高め。

プラスチック：
幅広く柔らかなハイライト。
明るくポップ。

ガラス：
透明物理シミュレーションは不要。
白い反射筋＋縁の明暗で表現。

ゴム：
マット。
輪郭側を少し暗く。
ハイライトごく弱い。

木：
固定方向の非常に薄い木目。
濃淡差小さめ。

石：
細かなムラ＋弱い不均一陰影。

重要：
陰影位置・ハイライト位置・木目方向・髪の流れ等は
templateごとの固定データ。

実行時ランダム禁止。

ノイズが必要な場合も、
templateId + regionId + paintTypeから固定seedを生成する。

同じ作品・同じ色・同じ画材なら
毎回同じ完成結果になること。

画材別スマート質感強度目安：

なめらか 100%
クレヨン 約70%
色えんぴつ 約55%

ただしプロトタイプの視覚検証結果を優先して調整する。


==================================================
15. 塗り方
==================================================

3種類：

- なめらか
- クレヨン
- いろえんぴつ

1作品内で混在可能。

領域を再度塗る場合：
以前の色や画材と混色せず、
新しい指定内容で完全上書き。

「ぬる」ボタンは存在しない。

デフォルト状態：
塗る。

消す：
明示的な「けす」アイコンをタップ。

消す状態で色を選択したら、
自動的に塗る状態へ戻る。

画材変更だけでは、
消す状態を勝手に解除しない。

Undo / Redoボタンは置かない。


==================================================
16. 塗り広がり演出
==================================================

競合アプリとの差別化目的ではなく、
「塗った感覚」を返す操作フィードバックとして実装する。

タップ地点から広がる。

完成状態はタップ地点に依存しない。

なめらか：
柔らかく広がる。

クレヨン：
粗い粒・短い塗りストローク感。

色えんぴつ：
細い線が走る感覚。

目安：
150～220ms。

演出完了待ちでUI入力をブロックしない。

高速連続タップ可能。

24. 完成演出
==================================================

完成ボタン選択後：

約1.8秒を標準。

「できた！」
などの文字は表示しない。

0.00～0.20秒：
ツールバー・パレットが軽くfadeしながら退く。

0.20～0.55秒：
作品を
98% → 102% → 100%
程度で軽く弾ませる。

0.40～1.15秒：
作品で実際に使用した色を基準に、
6～10個程度の色のしずくが周囲へ飛ぶ。

作品そのものを隠さない。

0.80～1.45秒：
作品外周付近に
小さな光・星を3～6個程度。

1.45～1.80秒：
演出を収束。

そのまま仕上げUI：

[はいけい]
[かざりわく]

[さくひんへ]

補助：
[もうすこしぬる]

へ移行。

完成ボタンを押した瞬間、
まず作品状態を保存する。

未着色部分があっても完成可能。

採点・完成率表示・警告はしない。

「演出をひかえめにする」がONの場合：
約0.3秒のfade＋弱い光だけ。

- background/frame切替で長時間freezeしない

**A04-01：キャンバス端でピンチ縮小すると、絵が余分に移動する**

- **Severity：P2**

- **根拠：** `apps/web/src/components/ArtworkCanvas.tsx:215` で呼ぶ `zoomViewportAt` は、`packages/coloring-engine/src/geometry.ts:25` ですでに移動範囲を制約する。その後、`ArtworkCanvas.tsx:222` で指の中心位置の移動量を加え、再度制約している。最初の制約で捨てた移動量が戻らず、ピンチ全体の座標変換が崩れる。
- **再現：** 表示領域を400×500 CSS px、表示を`scale=2, x=0, y=0`にする。2本の指をローカル座標`(100,250)`と`(300,250)`に置き、後者だけを`(250,250)`へ移動する。実コンポーネントのPointerイベント処理で再現した。

| 値 | 正しい変換を一度だけ制約 | 実測 |

| scale | 1.5 | 1.5 |

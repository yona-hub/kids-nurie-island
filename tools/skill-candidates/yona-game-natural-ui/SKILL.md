# ゲームUIを自然な見た目にする

利用者の継続的な希望は、ゲームのボタンを白い縁取り・角丸の囲い・二重枠などで一律にカード化しないこと。2026-10-10に「この枠線に関しては全ゲーム制作のときにお願いしたい」と明示された。

- 装飾のためだけのボタン枠線を初期状態に付けない。イラストの輪郭、余白、配置、文字、必要な面の色で操作対象を伝える。画像メニューは素材が自然に画面へ溶け込む構成にする。
- 単にborderを消して、同じ強さの輪郭をbox-shadowや擬似要素へ移すことはしない。外側の硬い板状影や定型のカード背景も、囲いとして見えていないか実画面で確認する。
- 透明画像の周囲に不自然な面が残る場合は、素材のalphaだけでなく親要素の背景・影・filterも調べる。薄い影や低い不透明度の四角い面も、透明なイラストの外縁を囲って見せない。
- 押下・hover・選択・無効状態は見分けられるようにする。キーボードのfocus-visible表示は残す。入力欄、ゲーム盤の境界、選択範囲など意味を持つ線まで一律に消さない。
- 当該ゲームの素材・世界観に合わせる。この希望を理由に、全ゲームへ同じ色、影、形、レイアウトを持ち込まない。
- 利用者の新しい具体的な指示を優先する。既存ゲームの変更範囲や外部公開の許可は拡張しない。

制作後は通常表示と操作状態を実画面で見て、装飾枠の代用品が増えていないこと、操作対象と文字が読み取れることを確認する。
